لغة CSS ودورها في تصميم صفحات الويب

المقدمة عرض الموضوع المراجع

أولاً: المقدمة

تُعد لغة Cascading Style Sheets (CSS)، واختصارها CSS، من الأدوات الأساسية لتصميم وتنسيق صفحات الويب. فهي تعمل مع لغة HTML لتحويل الهيكل البرمجي إلى واجهات جميلة ومريحة للمستخدم، من خلال التحكم في الألوان والخطوط والأبعاد والتخطيطات المختلفة.

وتمنح CSS مطوري المواقع القدرة على إنشاء صفحات متناسقة ومتجاوبة مع أحجام الشاشات والأجهزة المختلفة، كما توفر أدوات متعددة لتنظيم العناصر وتحديد طريقة ظهورها.

صورة توضيحية عن CSS وتصميم واجهات صفحات الويب.

ثانياً: عرض الموضوع

1- محددات CSS (Selectors)

تُستخدم المحددات لاختيار عناصر HTML التي نريد تطبيق قواعد التنسيق عليها. ويوضح الجدول التالي مجموعة من المحددات الشائعة:

المحدد الوصف مثال
محدد العنصر (Element) استهداف العناصر مباشرة باستخدام اسم الوسم. p { color: blue; }
محدد الفئة (Class) استهداف العناصر التي تحمل فئة معينة، ويبدأ بنقطة. .btn { background: red; }
محدد المعرّف (ID) استهداف عنصر يحمل معرّفاً محدداً، ويبدأ بالرمز #. #header { height: 80px; }
المحدد الشامل (Universal) استهداف جميع عناصر الصفحة. * { margin: 0; }
محدد العناصر المتداخلة (Descendant) استهداف عنصر موجود داخل عنصر آخر. div p { color: green; }
الفئة الزائفة (Pseudo-class) تطبيق تنسيق عند تحقق حالة معينة للعنصر. a:hover { text-decoration: underline; }

2- نموذج الصندوق (Box Model)

يعتمد نموذج الصندوق على تقسيم كل عنصر إلى أجزاء تساعد على التحكم في حجمه والمسافات المحيطة به. ويتكون من:

  • Content (المحتوى): النص أو الصورة أو المحتوى الفعلي داخل العنصر.
  • Padding (الحشو الداخلي): المسافة بين المحتوى والحدود.
  • Border (الحدود): الإطار المحيط بالمحتوى والحشو.
  • Margin (الهامش الخارجي): المسافة الخارجية بين العنصر والعناصر المجاورة.

مثال على بعض خصائص نموذج الصندوق: width: 300px; padding: 20px; border: 2px solid #333; margin: 15px auto;

3- التخطيط المرن (Flexbox)

Flexbox هو نظام تخطيط أحادي الاتجاه؛ أي إنه ينظم العناصر في صف أفقي أو عمود رأسي. ويساعد على توزيع المساحات ومحاذاة العناصر بسهولة.

من الخصائص المستخدمة معه: display: flex; و flex-direction: row; و justify-content: space-between; و align-items: center; و gap: 10px;.

4- شبكة التخطيط (CSS Grid)

CSS Grid هو نظام تخطيط ثنائي الاتجاه، إذ يتيح تنظيم العناصر في صفوف وأعمدة في الوقت نفسه، ولذلك يناسب تصميم التخطيطات الأكثر تعقيداً للصفحات.

مثال: display: grid; و grid-template-columns: repeat(3, 1fr); و gap: 20px;.

5- أهمية تعلم CSS

يعتمد تعلم CSS والتمكن منها على الممارسة والتجربة المستمرة. وتساعد معرفة المحددات ونموذج الصندوق وأنظمة التخطيط على بناء واجهات ويب منظمة وسهلة الاستخدام ومتجاوبة مع الأجهزة المختلفة.
